2. CÓDIGO QUE DEBE ESCRIBIR — ESCRIBIR:
Fragmento real dentro del return de ListaReportes:

<div className="lista-reportes">
  {reportes.map((reporte) => (
    <Reporte key={reporte.id} reporte={reporte}
      eliminarReporte={eliminarReporte} cambiarEstado={cambiarEstado} />
  ))}
</div>

HABLAR MIENTRAS ESCRIBE:
“map recorre el array y devuelve un componente Reporte por objeto. No modifica el array original. Las llaves permiten usar JavaScript dentro de JSX. Cada tarjeta recibe su objeto y las funciones de acción”.

3. PANTALLA:
Señalar key y el import de Reporte en el original.

HABLAR:
“key ayuda a React a reconocer cada elemento entre renderizados. Usamos el id, no la posición, porque al eliminar una tarjeta las posiciones cambian. key no es una prop normal que podamos leer dentro de Reporte: el id está en el objeto reporte”.

4. ESCRIBIR:
Fragmentos reales de Reporte.jsx. Están en diferentes posiciones del componente: la declaración antes del return; el párrafo dentro de article; los botones dentro de acciones.

const atendido = reporte.estado === 'Atendido';

<p className="descripcion">{reporte.descripcion}</p>

<button type="button" className="boton-estado" onClick={() => cambiarEstado(reporte.id)}>
  {atendido ? 'Volver a pendiente' : 'Marcar atendido'}
</button>
<button type="button" className="boton-eliminar" onClick={() => eliminarReporte(reporte.id)}>Eliminar</button>

HABLAR MIENTRAS ESCRIBE:
“atendido es una condición, no otro estado. El ternario elige el texto del botón. onClick recibe una función que llamará a la acción con el id correcto. Si ejecutáramos eliminarReporte directamente al renderizar, actuaríamos sin esperar el clic”.

PANTALLA:
Comparar lo escrito con Reporte.jsx; no guardar el borrador sobre el componente.

============================================================
PREGUNTAS QUE DEBO PODER RESPONDER
============================================================

¿Qué son props? Datos o funciones entregados por el componente padre.
¿map cambia el array original? No; devuelve otro array.
¿Para qué sirve key? Para identificar elementos de forma estable.
¿Por qué una flecha en onClick? Para esperar el evento y pasar el id.
¿Quién elimina realmente? La función eliminarReporte definida en App.

============================================================
ERRORES QUE NO DEBO COMETER

No usar el índice como explicación del id.
No decir que el hijo modifica las props.
No convertir la muestra estática en otra demostración funcional.
