GUÍA DE TRABAJO: AIDER LOCAL + OLLAMA + XAMPP + CODEIGNITER 4
Proyecto de Programación Web II
Ruta del proyecto:
C:\xampp\htdocs\S7\codeigniter4

Entorno:
- Windows
- XAMPP
- PHP 8.2.12
- CodeIgniter 4
- Aider instalado en el entorno Conda "aider"
- Ollama como servidor de modelos locales
- Modelo local recomendado para este Acer: qwen2.5-coder:3b

============================================================
1. IDEA GENERAL
============================================================

Aider NO depende de que el proyecto sea Python.

El entorno Conda "aider" solo sirve para ejecutar Aider y sus dependencias.
Aider puede leer y modificar archivos PHP, HTML, CSS, JavaScript, JSON, SQL, Fortran, C/C++, etc.

En este proyecto:

Aider
  -> lee/modifica archivos de CodeIgniter 4

Ollama
  -> ejecuta el modelo local offline

XAMPP
  -> proporciona Apache + PHP + MySQL/MariaDB

Git
  -> permite controlar y revertir cambios

============================================================
2. INICIO DE CADA SESIÓN
============================================================

PASO 1: Abrir Ollama.

Comprobar:
ollama list
ollama ps

PASO 2: Abrir Anaconda Prompt.

Activar Aider:
conda activate aider

PASO 3: Ir al proyecto:
cd /d C:\xampp\htdocs\S7\codeigniter4

PASO 4: Indicar la dirección local de Ollama:
set OLLAMA_API_BASE=http://127.0.0.1:11434

PASO 5: Comprobar PHP de XAMPP:
C:\xampp\php\php.exe -v

PASO 6: Iniciar Aider:
python -m aider --model ollama_chat/qwen2.5-coder:3b

3. PREPARAR GIT SOLO LA PRIMERA VEZ
============================================================

Comprobar:
git status

Si NO es un repositorio:

IMPORTANTE:
No versionar secretos ni credenciales. Normalmente .env no debe entrar al repositorio.

Si todo está correcto:
